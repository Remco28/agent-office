# Saved voices

Confirmed voice briefs that are meant to be reused across projects, one file
per voice, in the shape of [`../template.md`](../template.md).

- Name the file after the voice, not the project: `personal-blog.md`, not
  `my-app.md`.
- Strip anything project-specific; a project's own brief stays in that
  project (usually `docs/VOICE.md`).
- Only add a voice the human has confirmed, and only when they want it
  available elsewhere.
- When reusing one, still show it to the human in a line and ask whether it
  fits this piece. A saved voice is a starting point, not a standing approval.
