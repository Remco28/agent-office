# Saved voices

This folder holds confirmed voice briefs meant for reuse across projects, one file per voice, in the shape of [`../template.md`](../template.md).

- Name the file after the voice, not the project: `personal-blog.md`, not `my-app.md`.
- Strip anything specific to one project. A project's own brief stays in that project, usually as `docs/VOICE.md`.
- Only add a voice the human has confirmed, and only when they want it available elsewhere.
- When you reuse one, still show it to the human in one line and ask whether it fits this piece. A saved voice is a starting point, not a standing approval.
